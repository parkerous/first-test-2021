📋 Live stat sheet

Connect a Google Sheet and the Stats page shows it live — every stat you log in the sheet appears on the site automatically. Start from the official template (it has an Instructions tab): ⬇️ Download the stat sheet template. Import it at sheets.google.com (File → Import), set Share → Anyone with the link → Viewer, then paste the sheet's link here. (Any direct CSV link works too.) Row 1 of the sheet becomes the column headers, and every number column becomes a leaderboard category.
