Type set scores as 25-20, 23-25, 15-10 and save — or A 2-0 / B 2-0 for a result with no point scores (e.g. a forfeit). Save an empty box to clear a result.

💬 Discord webhook

In Discord: Server Settings → Integrations → Webhooks → New Webhook → pick the channel → Copy Webhook URL and paste it here (saved only on this device). Posts use Discord's live timestamps, so every member sees times in their own timezone.

⚡ Slash command — let members type /binsustar in Discord

Needs the shared Cloudflare Worker deployed (it answers Discord's requests). One-time setup: discord.com/developers → New Application → copy the Application ID and Public Key (General Information) and the Token (Bot tab) → paste below → Register. Then set the app's Interactions Endpoint URL to https://<your-worker>/interactions and invite the app to the server. The bot token is used once to register and is never stored.

🤖 Automatic posts — the Worker posts on its own schedule

Needs the shared Cloudflare Worker deployed with a cron trigger (see DEPLOY.md). Save your webhook here and the Worker posts by itself: match-night hype ~1 hour before the first serve, the Pick'em reminder at 12:00 GMT+8 on match days, and final scores the moment a result is saved. The webhook is stored only in your Worker's private storage — never in this browser or the site code.

👤 Players rosters · stat logging▾

👤 Add a player

All 161 registered players are already loaded. Add new signings here — the position's first entry decides which leaderboard they race on (Setter → Setters, Libero → Liberos, everything else → Hitters).

📊 Log stats

Pick a team, update the numbers after each game (season totals) and hit 💾 per player. Columns: G games · K kills · A aces · B blocks · D digs · As assists.

🏐 Preseason scrim results · teams▾

🏐 Post a game result

Pick both teams and enter each set's score. Add up to 5 sets — works for BO3 (2–3 sets) and BO5 (up to 5). The winner and all standings (record, set win-rate, point differential) are calculated automatically.
